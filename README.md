# Introduction to Optimal Control for Robotics
These two exercises in Jupyter Notebook implement a *Trajectory Optimization* and *Model Predictive Control* open-loop scheme for a *Linear Inverted Pendulum Model* (LIPM) 
using the *Zero Moment Point* (ZPM), and a factorization of the *Karush-Kuhn-Tucker* (KKT) matrix using Riccati backward and forward recursion.
